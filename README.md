# 🍕 Swiggy Sathi AI

An AI-powered Swiggy customer care assistant built using **Google Gemini API**, **Prompt Engineering**, and **Streamlit**.

This chatbot helps users solve food delivery-related issues like delayed orders, refunds, payment problems, wrong deliveries, and restaurant queries — just like a real customer support agent.

---

# 🚀 Features

✅ AI-powered customer support chatbot
✅ Built with Google Gemini API
✅ Smart prompt engineering
✅ Off-topic query filtering
✅ Friendly conversational UI
✅ Handles delivery & refund issues
✅ Real-time AI responses
✅ Beginner-friendly AI project

# 📌 Supported Queries

The chatbot can help with:

* Order status

# ❌ Off-Topic Protection

The chatbot is designed to reject unrelated questions such as:

* Cricket
* Movies
* Coding homework
* Politics
* Weather
* General knowledge

This is implemented using custom prompt engineering and keyword filtering.

# ▶️ Run Locally

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Prachipandey28/Swiggy-Sathi-AI.git
```

---

## 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3️⃣ Add Gemini API Key

Replace:

```python
API_KEY = "YOUR_API_KEY"
```

with your own Gemini API key.

Get free API key from:

https://aistudio.google.com/app/apikey

---

## 4️⃣ Run the App

```bash
streamlit run app.py
```
